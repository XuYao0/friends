# 剧本二次清洗规范

## 背景

一次清洗 agent 已对所有剧本 md 文件做了 Markdown 格式层面的规范化。  
本文件描述二次清洗的范围、规则和产出要求。

---

## 可自动处理（批量修复）

### 1. HTML/编码残片删除
- `?br>`、`br>`：直接删除该残片（保留残片前后的正常文字）
- `?/p>`、`?/i>`：直接删除
- `>From` 行首的 `>` 来自 HTML 引用标记：删除 `>`，保留 `From ...`

### 2. Mojibake 可推断时修正
常见规律是 GBK/Latin-1 混编或 OCR 误识，以下是已知映射（发现新的随时补充）：
- `慍handler` / `慍ause` / `慍ome` → 首字母还原为 `C`（`Chandler`、`Cause`、`Come` 等）
- `抎` → `d`（如 `where抎` → `wher'd`，`I抎` → `I'd`）
- `憂obody` → `Nobody`
- `慐gg` → `Egg`
- `扝ey` → `Hey`
- `慘ay` → `Day`
- `慓eller Bowl` → `Keller Bowl`（结合上下文确认）
- `揜iding` → `Riding`
- `揑'll` → `I'll`
- `fianc閑` → `fiancée`
- `runnin?out` → `runnin' out`（`?` 是撇号损坏）
- 其他单个乱码字符结合上下文推断，无法确认时不改，记录到人工核对文件

### 3. 明显 speaker 拼写错误修正
- `RAHCEL:` → `RACHEL:`
- `Racel:` → `Rachel:`
- `MOnica:` → `Monica:`
- `Moncia:` → `Monica:`
- `Pheobe:` / `Phoene:` → `Phoebe:`
- `Chander:` → `Chandler:`
- `Rosss` → `Ross's`（视上下文）
- 其他明显笔误，结合上下文确认后修正

### 4. 转录者注记删除
- 花括号内容 `{...}` 一律删除整行（或整段，如果跨行）
- 包括：`{Transcriber's Note: ...}`、`{Actually, ...}` 等

### 5. End 之后的非正文内容删除
- 找到独立一行的 `End`（大小写不限，含 `THE END`）后，删除其后所有内容
- `End` 本身规范化为 `*[END]*`

### 6. 文件开头正文前的站点宣传/导航文本删除
- 正文开始前如有站点导航、宣传、售卖信息等与剧本内容无关的文本，删除

### 7. 中文注释删除
- `*(毛巾)*` 等嵌入的中文括号注释：删除整个 `*(中文)*` 片段

### 8. 影响语义的单词粘连修复
- 仅修复两个英文单词之间完全缺失空格且影响阅读的情况，例如：`!How` → `! How`（若明显是两个词）
- 标点后紧跟字母（如句号、感叹号后无空格）可修复
- 轻微排版不整齐不处理

### 9. 明显英文拼写错误修正
- 台词、舞台说明、场景标注中明显的单词拼写错误可直接修正，例如：`agressive` → `aggressive`、`allways` → `always`、`belive` → `believe`
- 仅修正拼写（字母增删/换位），不改变词义、不改写句子
- 无法确认是拼写错误还是角色口音/方言的情况（如 `runnin'`、`gonna`），不修改

## 不处理（记录到人工核对文件）

以下问题需要人工结合视频核对，**不自动修改，逐条追加到 `workzone/人工核对.md`**：

- **空台词**：`ROSS:`、`JOEY:` 等 speaker 后面没有任何内容的行
- **完全无法推断的乱码**：如 `???????`、多个连续损坏字符
- **缺失 scene marker**：如 S02E03 开头直接进入对白
- **集数编号疑问**：如 S04E23 重复
- **模糊 speaker 归属**：冒号可能在句内、说话人指向不明确
- **模糊 action/scene 边界**：`*[...]*` 内容可能是 action 也可能是 scene
- **内容疑问**：地名/人名可能有误但无法仅凭文本确认（如 `Central Park` vs `Central Perk`）
- **转录者插入的外部注记嵌在对白内**且删除会破坏上下文的情况

## 产出要求

1. 修改对应的剧本 md 文件（`screenplays/converted_chunks/老友记_1-10季剧本_by_episode/`）
2. 将所有需要人工核对的问题逐条追加到 `workzone/人工核对.md`，格式：

```
### 文件名（如 052_S03E05.md）
- 问题描述，行号（如已知）
```

3. 参考来源：`screenplays/converted_chunks/clean_agent_logs/` 下对应的日志文件，以及 `workzone/剧本清洗.md` 中的人工记录
