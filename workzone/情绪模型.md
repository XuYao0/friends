# 情绪模型

本文档用于整理长期对话情感识别任务的情绪理论基础、候选标签体系和当前采用的标注 schema。

## 当前采用方案：任务基本情绪标签

当前任务不直接采用某一个理论家的完整基础情绪表，也不直接采用 Plutchik 24 个强度词作为标签。标签采用面向 Friends 长期对话情感识别任务的基本情绪集合，并要求模型为非 `neutral` 情绪额外标注强度。

可用标签如下：

| emotion | 中文 | 说明 |
| --- | --- | --- |
| anger | 愤怒 | 被冒犯、被阻碍、不公对待或目标受损时的对抗性情绪。 |
| disgust | 厌恶 | 对对象、行为、想法或情境产生反感、排斥或想远离。 |
| fear | 恐惧 | 面对威胁、危险、惩罚、损失或坏结果预期时的防御性情绪。 |
| happiness | 快乐 | 一般正向愉悦、高兴、开心或愿望满足。 |
| surprise | 惊讶 | 现实突然偏离预期时的定向反应，可正向、负向或中性。 |
| sadness | 悲伤 | 失去、失败、分离、拒绝、失望或关系受损引发的低落。 |
| contentment | 满足 | 需求被满足、处境舒适安稳、没有急迫未满足需求时的平静正向情绪。 |
| relief | 如释重负 | 先前威胁、压力、担忧或坏结果预期解除后的放松性正向情绪。 |
| interest | 兴趣 | 注意被对象、信息、人物或可能性吸引，并想继续了解、观察或参与。 |
| contempt | 轻蔑 | 对对象产生贬低性评价，认为其愚蠢、低劣、不值得尊重或可笑。 |
| shame | 羞耻 | 自我形象、身份或价值暴露出缺陷时产生的自我否定和想隐藏的情绪。 |
| guilt | 内疚 | 认为自己做错事、伤害别人、违反责任或承诺时产生的自责。 |
| embarrassment | 尴尬 | 轻度社交失误、失态、被撞见、私人信息暴露或场面不合适引发的不适。 |
| neutral | 中性 | 无明显情绪，或证据不足以判断具体情绪。 |

`intensities` 用于标注各情绪的强度，取值为：

| intensity | 中文 | 说明 |
| --- | --- | --- |
| low | 弱 | 情绪存在但轻微，语气、行为或上下文只显示低强度倾向。 |
| medium | 中 | 情绪明确可识别，但没有达到强烈爆发、失控或极端状态。 |
| high | 强 | 情绪强烈，通常伴随明显爆发、压倒性反应、强烈行动倾向或高度生理/行为表现。 |
| none | 无 | 仅用于 `neutral`。 |

推荐字段：

```json
{
  "emotions": ["relief", "happiness"],
  "intensities": ["medium", "low"],
  "reason": "The speaker relaxes because a feared bad outcome has just been avoided."
}
```

`emotions` 中的每个值都必须从上表选择。`intensities` 与 `emotions` 一一对应，长度必须相同。非 `neutral` 情绪的强度应为 `low`、`medium` 或 `high`；`neutral` 的强度固定为 `none`。如果标注为 `neutral`，则 `emotions` 只能为 `["neutral"]`，`intensities` 只能为 `["none"]`。不要为了覆盖所有可能感受而罗列情绪，只保留对解释当前台词真实情绪有实质贡献的情绪。

## 标签保留原则

一个标签是否保留为基本标签，不由某个理论体系单独决定，而由当前任务中的不可替代性决定。判断标准包括：

1. 它是否只是另一个标签的强弱、唤醒度或状态变化。
2. 它是否只是其他标签的混合，且用混合字段表达更自然。
3. 它是否有独立的 appraisal structure，即独立的触发条件和心理评价结构。
4. 是否存在常见场景，使它是最自然的单一标签，而其他标签会明显丢信息。
5. 它在 Friends 长期对话中是否足够常见，并且标注员或 LLM 能否稳定区分。

按该原则，`contentment` 和 `relief` 虽然都属于正向情绪，但不被合并进 `happiness`：`contentment` 的核心是需求满足后的安稳舒适，`relief` 的核心是坏结果解除后的释放。`contempt` 虽可近似为敌意和厌恶的组合，但它有独立的贬低性评价。`shame`、`guilt`、`embarrassment` 都属于自我意识或社会评价情绪，但分别对应自我价值受损、行为责任归因、轻度社交暴露。

`distress` 暂不作为基本标签。肉体痛觉本身不是情绪；痛觉引发的情绪性受苦可在 `reason` 或后续扩展字段中标注。若核心是威胁预期，用 `fear`；若核心是丧失、拒绝或失望，用 `sadness`；若核心是被冒犯或受压迫，用 `anger`。

## Plutchik 情绪轮参考

Plutchik 情绪轮在本文档中作为理论背景和参考，不作为当前任务 schema。它提供了一种心理进化论直觉：基础情绪不是任意命名的主观状态，而是在人类和动物中反复出现、服务于生存和适应的反应模式。也就是说，情绪之所以“真实”，不是因为它们只存在于语言分类中，而是因为它们对应相对稳定的刺激判断、身体感受、行为倾向和适应功能。例如，威胁引发恐惧并促成逃离，障碍引发愤怒并促成攻击或排除，失去重要对象引发悲伤并促成求助和重新整合。

这个 foundation 适合当前任务的原因是：剧本台词中的情绪往往不仅是面部表情或单句语气，而是人物在情境、关系、目标和长期事件压力下形成的适应性反应。Plutchik 模型把情绪、行为倾向和生存功能放在同一框架下，便于后续 Agent 结合人物记忆、事件记忆和当前对话解释“说话人真实情绪”。

  "emotion_components": ["joy", "trust"]

清洗阶段 `emotions` 和 `intensities` 可置为 `null`；标注阶段 `emotions` 应从当前采用方案的基本标签表中选择，`intensities` 应与 `emotions` 一一对应。Plutchik 的 `emotion_family`、24 个强度词、`compound_emotion` 和 `emotion_components` 可作为分析参考，但不作为当前标签 schema。

## 基本情绪标签解释

本节解释下方 Ekman / Izard / Plutchik 对照表中出现的所有唯一标签。这里解释的是基础情绪或准基础情绪概念，不是 Plutchik 24 个强度词，也不是 dyads 复合情绪。

`Anger`：愤怒，通常来自被阻碍、被冒犯、被不公对待或重要目标受损。它带有对抗、纠正、攻击或迫使局面改变的行为倾向。

`Disgust`：厌恶，指对某个对象、行为、想法或情境产生排斥感。它原本与污染、腐烂、危险食物等回避反应有关，也可扩展到道德厌恶和人际反感。

`Fear`：恐惧，指对威胁、危险或可能伤害的反应。它通常促使人逃离、回避、求助、防御或高度警觉。

`Happiness`：快乐，指愿望满足、关系顺利、目标达成或处境令人愉悦时产生的正向情绪。它可以从轻松愉快到强烈喜悦，但核心是积极评价和趋近倾向。

`Surprise`：惊讶，指现实突然偏离预期时产生的短暂定向反应。它本身可以是正向、负向或中性的，后续常迅速转化为快乐、恐惧、愤怒等更明确情绪。

`Sadness`：悲伤，通常来自失去、失败、分离、拒绝或重要期待落空。它带有低能量、退缩、求助、反思或重新整合的倾向。

`Distress`：痛苦或苦恼，Izard 用它替代 `Sadness` 作为基础情绪之一。它更强调直接的负性痛感、受苦和不适，不一定包含 `Sadness` 中较强的认知评价、失落叙事或反思成分。

`Contempt`：轻蔑，指对他人低劣、愚蠢、无价值或不配尊重的评价。它与 `Disgust` 和 `Anger` 相近，但更强调居高临下的贬低，而不只是反感或敌意。

`Shame`：羞耻，指个体认为自我形象、身份或价值暴露出缺陷时产生的痛苦感。它通常伴随想隐藏、逃避目光、降低存在感或修复自我形象。

`Guilt`：内疚，指个体认为自己做错事、伤害他人或违背责任时产生的负性情绪。它比 `Shame` 更聚焦具体行为和责任，而不是整个自我价值。

`Embarrassment`：尴尬，通常来自轻度的社会失误、失态、被注意或不合时宜的暴露。它比 `Shame` 更短暂、更轻，常可通过笑、道歉、转移话题来缓解。

`Amusement`：被逗乐或觉得好笑，来自幽默、荒诞、轻松的不协调或社交玩笑。它是正向情绪，但比 `Happiness` 更具体地指向娱乐性和笑意。

`Contentment`：满足或知足，指人在需要被满足、处境安稳或关系良好时产生的平静正向情绪。它不像 `Excitement` 那样高唤醒，而是低唤醒、稳定、舒适。

`Excitement`：兴奋，指对即将发生或正在发生的积极事件产生的高唤醒正向情绪。它通常包含期待、能量上升和行动准备。

`Pride in Achievement`：成就自豪，指个体因完成目标、表现优秀或获得认可而产生的自我肯定。它与普通 `Happiness` 不同，核心是“这是我做到的”。

`Relief`：如释重负，指威胁、压力、担忧或不确定坏结果解除后产生的放松感。它常常跟先前的恐惧、焦虑或压力相连。

`Satisfaction`：满意，指结果符合标准、目标完成或需求得到满足后的正向评价。它比 `Contentment` 更偏向对结果的判断，比 `Happiness` 更克制。

`Sensory Pleasure`：感官愉悦，指由味觉、触觉、气味、声音、视觉等身体感官带来的快乐。它不一定涉及复杂社会评价或长期目标，重点是直接的身体享受。

`Interest`：兴趣，指被对象、信息、活动或可能性吸引并愿意继续探索。它是认知和动机色彩很强的情绪，通常推动注意、学习和接近行为。

`Anticipation`：期待或预期，指个体面向未来事件进行等待、准备、预测或趋近。它可以是积极期待，也可以带有紧张和警觉，核心是未来导向。

`Trust`：信任，指相信某人、某关系或某情境是可靠、安全、善意或可依赖的。它通常支持亲近、合作、开放和把控制权部分交给对方。

## 三种基础情绪理论的主张

### Ekman

Ekman 的核心依据是面部表情的跨文化识别一致性。其早期研究发现，来自不同文化的人对若干面部表情会给出高度一致的情绪标签；研究还扩展到缺少大众媒体暴露的巴布亚新几内亚 Fore 人群，用于反驳“表情意义完全由文化学习决定”的观点。

Ekman 的基础情绪主张可以概括为：情绪是真实的，因为不同文化的人对同一张脸给出相近标签，且若干情绪具有可识别的面部表达模式。早期常见六类为 anger、disgust、fear、happiness、sadness、surprise。后来 Ekman 扩展了基础情绪列表，加入 contempt、embarrassment、excitement、guilt、pride in achievement、relief、satisfaction、sensory pleasure、shame 等更宽的正负情绪。

### Izard

Izard 的核心依据是发展时间线和神经-动机功能。他的 differential emotions theory 认为，情绪是人格系统的核心组成部分，每种基础情绪都有相对独特的神经生物活动、表达模式、主观感受和行为驱动功能。Izard 还强调，即使是很小的婴儿也能表现若干基础情绪，这些情绪不是单纯通过社会学习获得，而是作为适应性行为逐渐显现。

Izard 的基础情绪主张可以概括为：情绪是真实的，因为它们按相对稳定的发展路径在婴儿身上出现，并且每种情绪都有独特的神经基础、表达模式和动机功能。其 1977 年理论列出的十种 primary and discrete emotions 为 fear、anger、shame、contempt、disgust、guilt、distress、interest、surprise、joy。

### Plutchik

Plutchik 的核心依据是进化适应功能和跨物种类比。他的 psychoevolutionary theory 把情绪理解为适应性行为模式的一部分，强调基础情绪与典型刺激、认知判断、行为反应和生存功能相连。

Plutchik 的基础情绪主张可以概括为：情绪是真实的，因为它们对应动物和人类共有的生存行为模式。其八个基础情绪为 joy、trust、fear、surprise、sadness、disgust、anger、anticipation，并以相对情绪、强度梯度和 dyads 的方式组织成情绪轮。

## 对当前任务的含义

当前任务采用本文开头的任务基本情绪标签作为 schema，并为非 `neutral` 情绪标注强度。Plutchik 情绪轮、Ekman 基础情绪和 Izard differential emotions theory 作为理论来源和对照材料，用于解释标签选择，而不直接决定最终标签集合。

当前已明确：

1. 不采用 Plutchik 24 个强度词作为标签。
2. 不把 Plutchik dyads 当作权威混合公式。
3. 保留 `contentment`、`relief`、`interest`、`contempt`、`shame`、`guilt`、`embarrassment`，因为它们在长期对话中有独立 appraisal structure 和不可替代场景。
4. 暂不保留 `distress` 为基本标签；痛觉或急性受苦可在 `reason` 或后续扩展字段中说明。
